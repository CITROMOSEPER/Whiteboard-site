打开应用

它能做的一切

每一个工具和技巧，按主题排列。每个主题都有带图片的分步教程。

自动规整的形状

在一笔结束时停住，它就会变成整齐的直线、圆、三角形或矩形。继续按住即可旋转和缩放。

拖动颜色来填充

从工具栏拖出一种颜色，放进任意闭合形状。放在线条或文字上则会改变它的颜色。

涂抹即可删除

像在纸上一样在错误上来回涂抹，它就会消失。改变主意时随时可以撤销。

荧光笔和激光笔

荧光笔会垫在字迹下方，让字迹保持清晰。激光笔会留下发光的轨迹，适合演示。

PDF 和纸张

打开 PDF 或新建固定纸张尺寸的页面，直接在上面书写。非常适合课程幻灯片和作业。

文字和手写

在需要的地方打字，或用手写并转换为文字。压感支持 Apple Pencil 和大多数 Windows 触控笔。

手写 AI

选中你写的内容：整理成排版规范的文字和公式，逐步求解方程，或把函数变成可以探索的图像。

密钥绝不离开你的设备

AI 使用你自己的 API 密钥。它只保存在你的浏览器里，只会直接发送给你选择的服务商。没有 Whiteboard 服务器，白板、文件和链接也从不包含它。

一起实时画

分享一个链接，打开它的人就能和你实时在你的白板上一起画，每人都有自己颜色并带名字的激光笔。手机扫二维码即可加入。一切直接在你们的浏览器之间传送：没有服务器，也不用账号。

入门

  • 选择工具和颜色底部的工具栏里有笔、荧光笔、橡皮擦、文字等，旁边是你的颜色。
  • 调整画笔左侧的滑块调整粗细和不透明度，下方的按钮选择线条类型。
  • 移动视图用两指拖动或滚动来移动，双指缩放或按 Ctrl 加滚轮来缩放。“适合内容”可以让所有内容重新显示。

笔和颜色

  • 选择线条类型不透明度滑块下方的按钮可选择实线、点线、虚线、长虚线或点划线。
  • 调出任意颜色彩虹色块会打开调色器，支持 HEX、RGB 和 HSL，还有可以从白板上取色的吸管。
  • 用压感绘画在设置中打开“压感”：用触控笔按得越重，线条就越粗。

荧光笔、橡皮擦、激光笔

  • 标记重点荧光笔有自己的霓虹色。它会垫在字迹下方，让字迹保持清晰。
  • 擦除橡皮擦经过的地方墨迹会被擦掉，左侧滑块调整它的大小。触控笔的橡皮擦端也能用。
  • 用激光笔指示激光笔显示一个带短拖尾的发光点，适合演示。它不会画出任何东西，拖动会移动白板。

形状和颜色

  • 停住即可规整画完一笔后停住片刻：它会变成整齐的圆、直线、三角形或矩形。
  • 拖入一种颜色从工具栏拖出一种颜色，放进闭合形状即可填充。
  • 给线条改色把颜色放在线条、文字或填充上即可改变颜色。虚线依然保持虚线。
演示给我看

选择

  • 选择用选择工具点按对象，或画一个圈同时选中多个对象。
  • 移动、缩放、旋转在框内拖动可移动，拖动角或边可缩放，拖动上方的手柄可旋转。再用一根手指或按住 Shift 会对齐到 45°。
  • 之后再修改用选择工具点按一个形状，下方的工具条可以更改它的颜色、粗细和线条类型。
  • 复制、保存、删除顶部的工具条可以复制所选内容、存为贴纸或删除。

涂抹删除与撤销

  • 涂掉它像在纸上一样在错误上快速来回涂抹，它就会消失。底部会出现“撤销”。
  • 撤销和重做右上角的箭头用于撤销和重做。在触摸屏上，两指轻点撤销，三指轻点重做。

文字和手写

  • 打字选择文字工具，在要放文字的位置点按。上方的工具条设置字体、大小和颜色。双击文字即可编辑。
  • 手写在设置中打开“将手写转换为文字”，你手写的内容会变成打字的文字。
演示给我看

AI：整理、求解、作图

  • 添加你自己的密钥在 设置 → AI 中选择服务商并粘贴 API 密钥（“Get a key”会告诉你在哪里创建；Gemini 有免费额度）。密钥只保存在你的设备上，只发送给该服务商。
  • 整理手写选中你写的内容，点“AI”，再选“Tidy up handwriting”。它会变成打字文本，分数、幂和根号都排版规范。
  • 带步骤求解“Solve, showing the steps”会在题目下方写出解题过程。之后应用会把答案代回方程自行检验：✓ 表示答案成立。
  • 作图并探索“Plot as a graph”把写下的函数变成图像。双击它或点“Explore”即可在其中拖动和缩放；“Functions”可修改要画的函数。

图片和贴纸

  • 导入图片“导入…”可以把图片或 PDF 的页面放到白板上。
  • 缩放和旋转导入的图片处于选中状态：可以移动它，拖动角或边缩放，用手柄旋转。
  • 贴纸“存为贴纸”会保存一幅图以便重复使用。工具栏中的贴纸按钮可以把它放到任何白板上。
演示给我看

PDF 和纸张

  • 打开 PDF 或新建纸张在菜单中，“从…打开”会把 PDF 打开为可书写的页面，“新建纸张…”会新建一个固定纸张尺寸的页面。
  • 选择纸张尺寸A 系列和 B 系列、北美纸张、幻灯片和正方形，纵向或横向均可。
  • 书写、标记、添加页面直接在页面上书写和标记。页面上方或下方的 + 可以再添加一页。
  • 添加或删除页面页面上方或下方的 + 会添加一页同样大小的页面。两端的页面为空时，旁边的垃圾桶可以删除它。
演示给我看

图库和文件

  • 把白板放进图库“保存到图库”会按文件夹保存白板并显示预览。“备份…”会把整个图库保存为一个文件。
  • 保存为文件“另存为…”会把 .whtbd 文件保存到你选择的位置，“从…打开”可以再次打开它。Ctrl + S 会保存到同一位置。
  • 备份和恢复“备份…”会把整个图库保存为一个文件，“恢复…”可以把它找回来，“添加白板…”可以导入单个白板文件。

导出和分享

  • 导出PNG、JPEG、SVG、PDF 等格式。每个导出文件都包含白板本身，可以再次打开和编辑。
  • 包含图案打开“画布图案”，即可同时导出点、横线或网格。
  • 分享链接“分享链接…”把整个白板放进一个链接并让它变为实时：打开的人会得到副本，只要你的白板开着，就能和你一起在上面画。不经过任何服务器。
  • 打开分享的链接在没有地址栏的已安装应用中，“打开分享链接…”可以打开别人发给你的链接。
演示给我看

实时白板：一起画

  • 分享并开启实时“分享链接…”会生成一个链接，它带着白板的副本，并让白板变为实时。手机扫描二维码即可加入；在电脑上，把短代码输入“打开分享链接…”。“停止”即可结束；白板仍留在你这里。
  • 看见彼此线条在画的同时就会出现；使用激光笔时，每个人的指针都带着名字显示：发起者是红色，每位加入者都有自己的颜色。指向你正在探索的函数图像时，所有人都会看到你的指针停在曲线的同一点上。
  • 谁是谁点按“实时”徽标，查看白板上的每个人及其颜色。点按自己的名字可输入昵称；其他人会在列表中和你的指针旁看到它。
  • 如果连不上一些学校、大学和移动网络会阻止直接连接。这时链接仍可打开一份副本；如果你有自己的 TURN 服务器，可在 设置 → 实时白板 中填写。

设置

  • 浅色、深色和画布颜色在设置中可以选择主题和白板颜色：浅色、深色、跟随主题，或你自己调的颜色。
  • 点、横线或网格画布可以是空白、点阵、像笔记本一样的横线，或网格。
  • 语言应用支持 14 种语言，并跟随你的设备；也可以在这里选择其他语言。
