一款支持触控笔、手指和鼠标的快速白板，直接在浏览器中运行。形状自动规整，拖动颜色即可填充，白板保存在你自己的设备上。

手感像纸，整齐如软件。

汇集绘图应用的精华，在安静的玻璃质感界面中，不打扰你的思路。

自动规整的形状

在一笔结束时停住，它就会变成整齐的直线、圆、三角形或矩形。继续按住即可旋转和缩放。

拖动颜色来填充

从工具栏拖出一种颜色，放进任意闭合形状。放在线条或文字上则会改变它的颜色。

涂抹即可删除

像在纸上一样在错误上来回涂抹，它就会消失。改变主意时随时可以撤销。

荧光笔和激光笔

荧光笔会垫在字迹下方，让字迹保持清晰。激光笔会留下发光的轨迹，适合演示。

PDF 和纸张

打开 PDF 或新建固定纸张尺寸的页面，直接在上面书写。非常适合课程幻灯片和作业。

文字和手写

在需要的地方打字，或用手写并转换为文字。压感支持 Apple Pencil 和大多数 Windows 触控笔。

手写 AI

选中你写的内容：整理成排版规范的文字和公式，逐步求解方程，或把函数变成可以探索的图像。

密钥绝不离开你的设备

AI 使用你自己的 API 密钥。它只保存在你的浏览器里，只会直接发送给你选择的服务商。没有 Whiteboard 服务器，白板、文件和链接也从不包含它。

一起实时画

分享一个链接，打开它的人就能和你实时在你的白板上一起画，每人都有自己颜色并带名字的激光笔。手机扫二维码即可加入。一切直接在你们的浏览器之间传送：没有服务器，也不用账号。
