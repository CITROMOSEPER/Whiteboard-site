アプリを開く

できることのすべて

すべてのツールとコツを、トピックごとに。各トピックに画像付きの手順ガイドがあります。

形が整う

線の終わりで止めると、きれいな直線・円・三角形・四角形に変わります。そのまま押さえると回転や拡大縮小もできます。

色をドラッグして塗る

ドックから色を引き出して、閉じた図形の中に落とします。線や文字に落とすと色が変わります。

塗りつぶして消す

紙のように、間違いの上を往復してぐしゃぐしゃっと描くと消えます。気が変わったら取り消せます。

蛍光ペンとレーザー

蛍光ペンは文字の下にもぐるので、文字はくっきりしたまま。レーザーポインターはプレゼン用に光る軌跡を残します。

PDF と用紙

PDF を開くか、決まった用紙サイズのページを作って、その上に直接書き込めます。講義スライドや宿題にぴったり。

テキストと手書き

必要な場所に入力したり、手書きしてテキストに変えたりできます。筆圧は Apple Pencil と多くの Windows 用ペンで使えます。

手書きのための AI

書いたものを選ぶだけ。数式をきれいに組んだテキストに清書したり、方程式を途中式つきで解いたり、関数を自由に動かせるグラフにしたりできます。

キーはデバイスから出ません

AI はあなた自身の API キーを使います。キーはブラウザ内にだけ保存され、選んだプロバイダーへ直接送られるだけです。Whiteboard のサーバーはなく、ボードやファイル、リンクにキーが含まれることもありません。

はじめに

  • ツールと色を選ぶ下のドックには、ペン、蛍光ペン、消しゴム、テキストなどがあり、その横に色が並んでいます。
  • ブラシを調整する左のスライダーで太さと不透明度を変えます。その下のボタンで線の種類を選びます。
  • 移動する2 本指でドラッグするかスクロールで移動、ピンチか Ctrl + ホイールで拡大縮小。「内容に合わせる」ですべてが画面に戻ります。

ペンと色

  • 線の種類を選ぶ不透明度スライダーの下のボタンで、実線、点線、破線、長い破線、一点鎖線を選べます。
  • 好きな色を作る虹色のボタンで色ミキサーが開きます。HEX、RGB、HSL と、ボードから色を拾うスポイトが使えます。
  • 筆圧で描く設定の「筆圧」をオンにすると、スタイラスを強く押すほど線が太くなります。

蛍光ペン・消しゴム・レーザー

  • マークする蛍光ペンには専用のネオンカラーがあります。文字の下にもぐるので、文字はくっきりしたままです。
  • 消す消しゴムは通ったところのインクを消します。左のスライダーで大きさを変えます。スタイラスの消しゴム側も使えます。
  • レーザーで指すレーザーポインターは短い軌跡付きの光る点を表示します。プレゼン用で、描くことはなく、ドラッグするとボードが動きます。

図形と色

  • 止めて整える線を描き終えたら一瞬止めます。きれいな円・直線・三角形・四角形に変わります。
  • 色をドラッグするドックから色を引き出し、閉じた図形の中に落とすと塗りつぶされます。
  • 線の色を変える線、文字、塗りに色を落とすと色が変わります。破線は破線のままです。

選択

  • 選択する選択ツールで対象をタップするか、いくつかをまとめて囲みます。
  • 移動・拡大縮小・回転枠の中をドラッグで移動、角や辺で拡大縮小、上のつまみで回転します。もう 1 本の指か Shift で 45° ごとに揃います。
  • あとから変える選択ツールで図形をタップします。下のバーで色、太さ、線の種類を変えられます。
  • 複製・保存・削除上のバーで、選択したものを複製、ステッカーとして保存、または削除できます。

塗りつぶし削除と取り消し

  • 塗りつぶして消す紙のように、間違いの上をすばやく往復して描くと消えます。下に「取り消す」が出ます。
  • 取り消しとやり直し右上の矢印で取り消しとやり直しができます。タッチ画面では 2 本指タップで取り消し、3 本指でやり直しです。

テキストと手書き

  • 入力するテキストツールを選び、文字を置きたい場所をタップします。上のバーでフォント、サイズ、色を変えます。文字をダブルタップすると編集できます。
  • 手書きする設定の「手書きをテキストに変換」をオンにすると、手で書いた文字がテキストになります。
やり方を見る

AI：清書・解く・グラフ

  • 自分のキーを追加設定 → AI でプロバイダーを選び、API キーを貼り付けます（「Get a key」で取得場所がわかります。Gemini には無料枠があります）。キーはこのデバイスにだけ保存され、そのプロバイダーにだけ送られます。
  • 手書きを清書書いたものを選択し、「AI」から「Tidy up handwriting」を選びます。分数・累乗・根号がきれいに組まれたテキストになります。
  • 途中式つきで解く「Solve, showing the steps」は問題の下に途中式を書きます。そのあとアプリが答えを方程式に代入して自分で確かめます。✓ は合っているという意味です。
  • グラフにして探る「Plot as a graph」は書いた関数をグラフにします。ダブルタップするか「Explore」を押すと、中をドラッグしたりズームしたりできます。「Functions」で描く関数を変えられます。

画像とステッカー

  • 画像を入れる「インポート…」で画像や PDF のページをボードに置きます。
  • 大きさと向きを変える画像は選択された状態で置かれます。移動したり、角や辺で大きさを変えたり、つまみで回したりできます。
  • ステッカー「ステッカーとして保存」で絵を再利用できるように残せます。ドックのステッカーボタンで、どのボードにも置けます。
やり方を見る

PDF と用紙

  • PDF を開くか用紙を作るメニューの「場所を選んで開く…」で PDF を書き込めるページとして開きます。「新しい用紙…」で決まったサイズのページを作ります。
  • 用紙サイズを選ぶA 判と B 判、北米の用紙、スライドと正方形を、縦向きでも横向きでも。
  • 書く、マークする、ページを足すページに直接書き込み、蛍光ペンでマークできます。ページの上や下の + でページを追加します。
  • ページを追加・削除するページの上や下の + で同じサイズのページを追加します。端のページが空のあいだは、隣のごみ箱で削除できます。
やり方を見る

ギャラリーとファイル

  • ボードをギャラリーにしまう「ギャラリーに保存」でボードをフォルダごとにプレビュー付きで保存します。「バックアップ…」でギャラリー全体を 1 つのファイルに保存します。
  • ファイルに保存する「名前を付けて保存…」で .whtbd ファイルを好きな場所に保存し、「場所を選んで開く…」で開き直せます。Ctrl + S で同じ場所に保存します。
  • バックアップと復元「バックアップ…」でギャラリー全体を 1 つのファイルに保存し、「復元…」で戻せます。「ボードを追加…」で個別のボードファイルを取り込みます。
やり方を見る

書き出しと共有

  • 書き出すPNG、JPEG、SVG、PDF など。書き出したファイルにはボードそのものが入っているので、もう一度開いて編集できます。
  • 模様も含める「キャンバスの模様」をオンにすると、点、罫線、方眼も一緒に書き出せます。
  • リンクで共有する「共有リンク…」でボード全体を 1 本のリンクにします。サーバーを通らず、開いた人は自分用のコピーを受け取ります。
  • 共有リンクを開くアドレスバーのないインストール版アプリでは、「共有リンクを開く…」で送られたリンクを開けます。

設定

  • ライト・ダークとキャンバスの色設定でテーマとボードの色を選べます：ライト、ダーク、テーマに合わせる、または自分で作った色。
  • 点・罫線・方眼キャンバスは無地、点、ノートのような罫線、方眼から選べます。
  • 言語アプリは 14 言語に対応し、端末の言語に合わせます。ここで別の言語も選べます。
